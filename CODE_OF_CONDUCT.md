# Code of Conduct

## Our standards

We are committed to a welcoming, respectful, and harassment-free project. Examples of positive participation include using inclusive language, accepting constructive feedback, focusing on what is best for the community, and showing empathy toward other contributors.

Unacceptable behavior includes harassment, discrimination, personal attacks, trolling, publishing another person's private information, sexualized language or imagery, and sustained disruption of project discussions.

## Scope

This code of conduct applies to repository issues, pull requests, reviews, discussions, and other spaces where someone represents this project.

## Enforcement

Report conduct concerns privately through the maintainer contact options on the repository owner's GitHub profile. Do not use a public issue when doing so would expose a target or sensitive information.

Maintainers may edit or remove comments, commits, code, issues, and other contributions that violate these standards. Temporary or permanent participation restrictions may be applied based on impact and repeated behavior. Reports will be handled as confidentially as reasonably possible.
